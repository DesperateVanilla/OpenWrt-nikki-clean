# OpenWrt Nikki Clean

此分支基于最新的 [OpenWrt-nikki](https://github.com/nikkinikki-org/OpenWrt-nikki) main，保留中文 LuCI 翻译，并移除默认中国 IP 绕过、CN DNS 规则和中国 DNS 服务器。订阅 HWID 是可选功能，默认关闭。

目前只构建 OpenWrt 24.10 的 aarch64_generic 与 aarch64_cortex-a53。安装包来自本仓库的 GitHub Releases，不再使用 nikkinikki.pages.dev。请参阅 [README.md](README.md) 获取完整的安装和更新说明。
